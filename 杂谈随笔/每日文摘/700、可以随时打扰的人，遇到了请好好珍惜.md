# 可以随时打扰的人，遇到了请好好珍惜

伴随着年龄增长，愈发明白，三两知心好友，胜过万千点头之交。朋友之乐，贵在那份踏实和信赖。

人生得一知己不易，一定要好好珍惜那些真正对你好的人。那些在大雨中为你撑伞的人，陪你彻夜聊天的人，陪你放声大哭的人，不远千里坐车来看望你的人，总以你为重的人......正是他们，组成我们生命中一点一滴的温暖。

如果你身边也有这样的朋友，一定要多主动联系，多花些时间和心思，走进Ta的内心和生活。

你能够随时打扰的人，一定很懂你，愿意被你随时打扰的人，真的很在乎你，遇到这样的人，一定要好好珍惜。

余生漫漫，来日方长，愿我们都能和，那个能随时打扰的好友，彼此温暖，一路相伴。
